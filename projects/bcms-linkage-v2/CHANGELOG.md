# 변경 내역

## V3 (V2 대비) — 반영·확인·갱신 → 3층 모형과 6개 품질 차원

### 개념 변경 (연구자 제안 반영)
- V2의 "반영·확인·갱신" 3상태를 **폐기**하고, 첨부 문서의 3층 모형(객체층·관계층·품질층)으로 교체.
- 품질층: 정합성·추적성·증빙성·책임성·최신성·환류폐쇄성 6개 차원. 문항은 "객체쌍 + 관계동사 + 품질조건".
- 관계층: V2의 관계유형 7개를 **관계동사 11개**로 교체(Arias 서술문의 영문 동사를 근거로 추출). 첨부 문서의 동사 중 일치·추적·증빙은 품질 차원과 겹쳐 품질층으로 이동(이중 계산 방지).
- 문항 108개 → **179개** (연결 문항 163: 31개 연결 × 5개 차원 + 환류 연결 8개 × 환류폐쇄성).
- 종합 문항을 차원별 7개(DQ01~07)로, 역문항을 차원 대응 4개(RV1~4)로 교체.

### 근거 체계
- 품질 차원마다 **T1(Arias·Białas 원문 인용) / T2(외부 문헌 후보) / T3(연구자 정의)**로 근거를 분리하고 근거 강도를 표시(환류폐쇄성 강 · 정합성/증빙성/책임성/최신성 중 · 추적성 없음).
- 인용문 64개 → **72개** (새 차원용 8개 추가, 모두 PDF 원문과 자동 대조).
- **외부 학술 문헌 12건**을 `sources.json`·`학술근거` 시트에 추가. 이 환경은 외부 사이트 접속이 차단되어 **서지만 웹 검색으로 확인**했고 원문 문장은 확인하지 못했다. verbatim 칸은 비워 두었으며 검증 스크립트는 이 칸이 원문 확인 없이 채워지면 실패한다.
- 정의서 17개 → 24개 (연결 품질, 3층 모형, 관계동사, 6개 차원, 근거 등급, 형성적 지수 등).

- 응답입력에 연결 ID·차원 태그 행을 추가해 연결 점수와 차원 점수를 `SUMIFS/COUNTIFS`로 계산.
- 검증 시트에 차원 간 상관 행렬(변별타당도), 차원 점수와 종합 문항의 수렴, 외부 문헌 확인 현황 추가.

## V2 (V1 대비)

### 방식
- 모든 근거를 PDF 원문과 자동 대조한 **영문 인용문(쪽 번호 포함)** 64개로 제시. 한국어 번역은 별도 열(연구자 번역·참고용).
- 연결마다 "인용이 확립하는 사실"과 "연구자 의견(해석·보완·가정 / 측정 지표화)"을 **열로 분리**.
- 연구자 의견에 해당하는 용어 17개를 `정의서`로 정의(인용 정의 / 연구자 정의 구분).
- 증거 등급을 V1의 A/B에서 **E1/E2/E3**으로 재정의.
- 연결을 **출발 → 도착 한 쌍**으로 정의하고 한 문장이 여러 연결을 담은 경우 쪼갬(25 → 31개). 문항 90 → 108개.
- 채택하지 않은 후보를 `보류연결`에 이유와 함께 기록.
