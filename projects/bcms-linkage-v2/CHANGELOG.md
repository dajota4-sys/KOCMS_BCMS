# 변경 내역

## V2 (V1 대비)

### 방식
- 모든 근거를 PDF 원문과 자동 대조한 **영문 인용문(쪽 번호 포함)** 64개로 제시. 한국어 번역은 별도 열(연구자 번역·참고용).
- 연결마다 "인용이 확립하는 사실"과 "연구자 의견(해석·보완·가정 / 측정 지표화)"을 **열로 분리**.
- 연구자 의견에 해당하는 용어 17개를 `정의서`로 정의(인용 정의 / 연구자 정의 구분).
- 증거 등급을 V1의 A/B에서 **E1/E2/E3**으로 재정의.
- 연결을 **출발 → 도착 한 쌍**으로 정의하고 한 문장이 여러 연결을 담은 경우 쪼갬(25 → 31개). 문항 90 → 108개.
- 채택하지 않은 후보를 `보류연결`에 이유와 함께 기록.
